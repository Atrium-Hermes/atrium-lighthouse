indexer and other APIs every run, and json-repair is the dependable cleanup step for malformed model/API
output (trailing commas, single quotes, unquoted keys, comments, Python literals, mid-structure
truncation) with a diff of what it changed. It complements (does not duplicate) the data-processing stack
already rented (`schema-extract`). Cheapest candidate too. The +1 raw invocation of the unattested,
niche crypto-DD skill doesn't outweigh attestation + fit + price.
